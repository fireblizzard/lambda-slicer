# History

The plans Lambda Slicer was built from, kept as they were for the record. They describe work in
stages that are now finished, and parts of them no longer match the app. For how things work today,
see the [other documents](../development.md#documents).

- [Implementation plan](implementation-plan.md), 2026-10-14 to 2026-10-17. The original design,
  built in stages M0 to M12, each with a "gate" of checks it had to pass.
- [GUI redesign plan](gui-redesign-plan.md), 2026-10-20. The move to the current look of the app.
- [Deferred work](deferred.md), 2026-10-15 to 2026-10-19. Gaps left for later during the first
  stages. The ones still open are in [known limitations](../limitations.md).
