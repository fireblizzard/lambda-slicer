# Interface languages

The GUI ships fourteen languages (implementation plan §8.1). Their catalogs are Fluent files in
`crates/lambda-slicer-gui/src/i18n/ftl/`, embedded in the binary.

## For translators

- Edit only the `.ftl` file of your language. `en.ftl` is the source, and every catalog has the
  same messages with the same `$arguments`.
- Each sentence is one message. Reorder the arguments as your language needs, and never build a
  sentence from several messages.
- Plural messages select on a number. Give every form your language uses for whole numbers: `one`
  and `other` in English, German, Finnish and Turkish, `one`, `few`, `many` and `other` in
  Russian, Ukrainian, Polish and Lithuanian, `zero`, `one`, `two`, `few`, `many` and `other` in
  Arabic, `other` alone in Chinese. Spanish, Portuguese, French and Italian also have a `many`
  form for round millions, which the current plural data does not select yet.
- Numbers come formatted with your language's separators. Write the percent sign or unit where
  your language puts it, for example `{ $percent } %` in French or `%{ $percent }` in Turkish.
- Player names, map names, paths, weapon names and times stay as they are.
- The first line of each catalog says whether it is a draft. A catalog counts as reviewed once a
  native-speaking player has checked it in the app. `Locale::reviewed` then lists it, and the
  settings window stops showing the draft notice.

## Checks

`cargo test -p lambda-slicer-gui` checks that

- every catalog parses and has exactly the English messages and arguments,
- every plural message has a form for each plural category whole numbers reach in its language
  (0 to 200, 1,000 and 1,000,000), using the rules Fluent itself picks,
- Russian, Ukrainian, Polish, Lithuanian and Arabic give the right form for 0, 1, 2, 5, 11, 21,
  22 and 25 (implementation plan §10), and Lithuanian and Arabic past 100 too,
- number separators come out as expected, and the pseudo-locale below keeps arguments as they
  are.

The plural rules Fluent uses, `intl_pluralrules` 7.0.2, get Lithuanian and Arabic wrong for
numbers such as 22 and 103, so the workspace uses a corrected copy ([vendor](../vendor/README.md)).

`lambda-slicer-gui --locale TAG --settings --screenshot OUT.png` renders a language and saves the
window, to check layout and glyphs. See [gui-text](gui-text.md) for right-to-left text.

## Pseudo-locale

`--pseudo` turns every message of the chosen language into a longer, accented version in
brackets, `Close` becoming `[Çļöšé~~]`. Text grows by two fifths, about as much as German, Finnish,
Russian or Polish often add, and names, paths and numbers given as arguments stay as they are. A
message cut off on screen lacks its closing bracket. It works with `--demo`, `--settings` and
`--screenshot` like any language.

Checked 2026-10-17 at 1280 by 800 and wider, with the library, settings, a demo with scores,
clips, export results, the timeline legend and the event table: every message kept its bracket
after two fixes. The scores pane counted the width of its scroll bar too late and shrank to an
earlier width, so its last heading was cut, and now stacks the teams sooner and takes the full
width. Columns past the window's edge in the full library scroll into view. Player names in lane
labels and table cells are cut with an ellipsis by design, as the columns can be widened.

## Status

All catalogs other than English are machine-assisted drafts awaiting review. They cover the
toolbar, settings, library list, filters, scanning, and every core message code
([messages](messages.md)). Tests check that English has every core code and every message id the
GUI source names, and that every catalog matches English.
